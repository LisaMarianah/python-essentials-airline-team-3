# Skylink Reservations

# Project Description
Skylink Reservations is a Python-based airline reservation system that allows users to manage flights, seats, passengers, bookings, and waitlists through a simple command-line interface.

# Features
- Add and manage flights
- Create validated seat maps
- Display flight seat maps and occupancy
- Register passengers
- Book available seats
- Cancel bookings
- Change passenger seats
- Add passengers to a waitlist
- Automatically promote passengers from the waitlist
- Display flight manifests
- Generate a revenue report

# Technologies
- Python 3/VS code
- Github
- Python dictionaries and lists

# How to Run
- Make sure Python 3 is installed.
- Clone or download the project repository.
- Open the project folder in your terminal.
- Run the program using python 
- Follow the menu prompts to use the reservation system.
